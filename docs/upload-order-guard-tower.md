# Upload-Reihenfolge – Guard Tower

1. `prompts/guard-tower-l1-l7.md`
2. `prompts/guard-tower-l1-l7.json`
3. `public/assets/manifests/guard-tower-levels.json`
4. `public/assets/metadata/personal-buildings/guard-tower/inpinity/level-1.json` bis `level-7.json`
5. `public/assets/metadata/personal-buildings/guard-tower/inphinity/level-1.json` bis `level-7.json`
6. danach die final generierten Bilder in:
   - `public/assets/images/personal-buildings/guard-tower/inpinity/`
   - `public/assets/images/personal-buildings/guard-tower/inphinity/`

## Interface-Test

- `building-level.html?building=guard-tower&faction=inpinity&level=1`
- `building-level.html?building=guard-tower&faction=inphinity&level=7`

## Hinweis

Wenn du weiterhin ein zentrales Gesamtmanifest nutzt, kannst du die 14 Guard-Tower-Einträge aus `guard-tower-levels.json` in dein Hauptmanifest übernehmen.
