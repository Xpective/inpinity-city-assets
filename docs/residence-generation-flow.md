# Residence – Produktionsfluss L1 bis L7

## Fixe Regeln

- immer dieselbe isometrische 3/4-Kamera
- immer ein einzelnes zentrales Gebäude
- keine UI, keine Schrift, keine Charaktere
- gleiche Seed-Familie pro Fraktion benutzen
- L2–L7 möglichst aus dem Vorlevel weiterentwickeln

## Reihenfolge

1. Inpinity L1–L7 generieren
2. Bestes Set auswählen
3. Inphinity L1–L7 generieren
4. Stil angleichen
5. Web/UI-Varianten aus denselben Motiven ableiten oder separat ruhiger rendern

## Visuelle Eskalation

- L1–L2: kleines Wohn- und Display-Gebäude
- L3–L4: Gallery-/Archive-Charakter sichtbar
- L5: Legacy/Trophy-Charakter sichtbar
- L6: Gallery Estate
- L7: Founder Residence Palace
